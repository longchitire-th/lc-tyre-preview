# LC TYRE — Local Design Preview

ต้นแบบแยกบนเครื่องสำหรับตรวจแบบก่อนพัฒนาใน WordPress เดิม ไม่ใช่ production site หรือ staging clone

## เปิดดู

เปิด http://localhost:3000/ บนเครื่องที่เปิดตัวอย่างนี้อยู่ หากปิดโปรแกรมแล้วให้เปิด terminal ในโฟลเดอร์นี้และรัน `npm install` ตามด้วย `npm run dev -- --host 127.0.0.1` แล้วเปิด URL ที่โปรแกรมแสดง

Node.js 22.13 ขึ้นไป หน้าเว็บไม่ต้องใช้ API key หรือข้อมูลล็อกอินร้าน

## ทดลอง

- ค้นหา 205/55R16, 205 55 16 หรือ 2055516
- กรองแบรนด์/Run Flat และเรียงราคา
- เปิดรายละเอียดสินค้าและ URL เดิม
- ทดลองเลือกสาขา/พาร์ตเนอร์และค่าติดตั้ง ไม่มีการส่งจองจริง
- เปิด LC Tyre AI เป็นแชตตามกฎ ยังไม่เชื่อม AI provider
- ทดลองหลังบ้าน → แคมเปญ → แก้ราคาโปรสาธิต ไม่มีการบันทึกลง WordPress

ข้อมูลและภาพสินค้าอ่านจาก WooCommerce Store API สาธารณะวันที่ 7 กันยายน 2026 รวม 33 รายการ ราคาและสถานะเป็น snapshot ไม่ใช่ live feed ไม่มี Orders/Customers ในโครงการนี้

แคมเปญ NAZZ และค่าบริการติดตั้งเป็นข้อมูลตัวอย่างจากบรีฟ ยังต้องตรวจเงื่อนไขจริง ไม่มีรีวิวหรือยอดขายสมมติ

## การตรวจสอบ

- Build ผ่าน
- TypeScript ผ่าน
- ทดลองค้นหา 2055516 ได้ผล 205/55R16
- ทดลองกรอง MICHELIN และเรียงราคาต่ำไปสูง
- ตรวจ viewport 390 และ 1440 px: ไม่พบ horizontal overflow และรูปภาพโหลดครบที่ตรวจ
- ไม่ได้ทดสอบ payment, order, booking availability, OEM หรือ AI จริง เพราะยังไม่เชื่อมระบบเหล่านี้
- Starter install รายงาน dependency vulnerabilities; ก่อนพัฒนา staging/production ต้องทำ dependency/security review อีกครั้ง ห้ามนำต้นแบบไปใช้เป็นระบบรับชำระเงินจริง

## สิ่งที่ยังรอ

Full website backup และ restore test ยังไม่ได้ทำ ต้องเข้าถึงโฮสติ้ง/ฐานข้อมูลก่อน การเชื่อมต่อแท็บ WordPress ที่เปิดอยู่ยัง timeout จึงยืนยันระบบหลังบ้านเพิ่มเติมไม่ได้

อ่าน LC-TYRE-Audit-and-Rollback.md สำหรับ architecture และแผนกู้คืน โดยห้ามทับฐานข้อมูลเก่าลง production จนทำออร์เดอร์ใหม่หาย

โครงการนี้คงไว้ local ตามการขอตรวจตัวอย่างก่อนใช้จริง ไม่ได้ deploy เปลี่ยน DNS หรือเปลี่ยน WordPress
